# Morivo MVP v0

This is the first real app scaffold after the prototype phase.

## Included
- Dashboard
- Create Experience with simulated AI generation
- Studio / flow builder
- Runtime
- Participant Mode
- Memory Engine
- Shared in-memory state across views

## Run locally
```bash
npm install
npm run dev
```

Then open http://localhost:3000
