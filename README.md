# Morivo MVP v5 — AI Experience Creator

Adds:
- Create with Morivo AI entry point
- Free-text experience description
- type/location/duration/participant context
- premium Morivo Thinking animation (routes, missions, puzzle, memory book; no spinner)
- AI-style first-draft generation into the existing editable Studio
- Hebrew RTL + English creation UI
- Blank Experience remains available and blank

Important:
This MVP intentionally uses an on-device draft generator so no API key or new backend is required yet.
It validates the complete AI UX and data flow before connecting a production model endpoint.

No Firebase Rules, Storage Rules, or Vercel environment changes are required.
